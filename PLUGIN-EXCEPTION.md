## Definitions

"The Program" means the Anima software distributed by Cocreiamo di Bilotta
Francesco under the AGPL, including the official plugins distributed as part
of it.

"Interfaces" means the means the Program provides to extend it: database
schemas, commands and views exposed to extensions, APIs, extension points,
configuration formats, and the interface definitions and code that the
Program's own tools generate for them.

"A Plugin" means a work that interacts with the Program only through its
Interfaces and that contains no part of the Program other than interface
definitions and the output of the Program's own tools.

"Configuration and Data" means settings, records and other content that a
user of the Program enters, imports or stores in it.

3. Configuration and Data are not a work based on the Program, and the AGPL
